# Reportix — AI-генератор отчётов и коммерческих предложений

Современная платформа для digital-агентств, маркетологов и фрилансеров в стильном тёмном чёрно-серебряном оформлении (Black & Silver).

---

### Новые функции и ключевые улучшения (Релиз v2.5.0)

#### 1. Исправление сохранения тарифов (Постоянная серверная персистентность)
* **Проблема решена**: Устранён баг, из-за которого назначенные тарифные планы сбрасывались на «Старт» при перезагрузке страницы, обновлении проекта или перезапуске сервера.
* **Надёжная архитектура сохранения**:
  * **Серверный реестр**: Данные о выданных тарифах сохраняются на сервере в `data/subscriptions.json` и синхронизируются через API (`/api/subscriptions`).
  * **Синхронизация с базой данных**: Автоматический upsert в таблицу Supabase `user_subscriptions`.
  * **Расчёт точного срока действия (`expiresAt`)**: Система рассчитывает дату окончания подписки (1 месяц, 3 месяца, 6 месяцев, 1 год или бессрочно). Тариф остаётся активным вплоть до наступления даты истечения.
  * **Кэширование на клиенте без задержки**: При перезагрузке страницы тариф считывается мгновенно из локального кэша без мигания и перехода в бесплатный режим, а затем валидируется с бэкендом.

---

#### 2. Регистрация с обязательным именем на английском языке
* **Валидация имени**: При создании аккаунта запрашивается «Full Name» с обязательными условиями:
  * **Только английский язык** (латиница A-Z и пробелы).
  * **Не менее 4 символов** (валидация длины и формата).
  * Кириллица, спецсимволы и цифры блокируются с понятным уведомлением.
* **Использование в системе**: Имя пользователя сохраняется в профиле, отображается в шапке сайта (`AppHeader`) и в реестре пользователей админ-панели.

---

#### 3. Экспресс-импорт из рекламных кабинетов и аналитики
* В форме создания отчёта (`/new`) добавлен интерактивный инструмент импорта в 1 клик:
  * **Яндекс Метрика**: визиты, глубина, отказы, цели, выручка.
  * **VK Реклама**: показы, клики, CTR, eCPC, лиды, eCPA, расход.
  * **Telegram Ads**: показы, подписки на канал, CPS, расход TON/Stars.
  * **Google Analytics 4**: сессии, активные пользователи, конверсии, каналы трафика.
* Система мгновенно подставляет структурированные метрики с динамикой и заметками.

---

#### 4. Готовые отраслевые шаблоны по узким нишам
* Вкладка быстрого выбора нишевых пресетов над формой создания:
  1. **Таргетированная реклама (VK & TG Ads)** — фитнес, бьюти, локальный бизнес.
  2. **Контекстная реклама (Яндекс Директ)** — медицина, B2B, недвижимость.
  3. **Комплексное SEO-продвижение** — интернет-магазины и каталоги.
  4. **SMM & Контент-маркетинг** — рестораны, ритейл, отели.
  5. **Коммерческое предложение на веб-разработку** — IT-студии и интеграторы.
  6. **Аудит юзабилити и конверсии** — e-commerce проекты.

---

#### 5. White-Label
* Функция отключена в текущей версии (упрощение продукта).

#### 6. Публичная онлайн-версия отчёта (Web-View) и Демо в 1 клик
* **Web-View по ссылке (`/view/$id`)**:
  * На странице отчёта добавлена кнопка **«Поделиться (Web-View)»**.
  * Ссылка копируется в буфер обмена. Заказчик может открыть интерактивный отчёт со смартфона или компьютера без регистрации.
  * Поддерживается скачивание PDF прямо со страницы просмотра.
* **Интерактивный демо-отчёт (`/demo`)**:
  * На главной странице размещена кнопка **«⚡ Демо в 1 клик (без регистрации)»**.
  * Посетитель сразу видит реальный высококонверсионный отчёт и может протестировать экспорт PDF.

---

#### 7. Управление и Админ-панель (`/admin`)
* **Главный администратор**: email и пароль задаются через `VITE_ADMIN_EMAIL` и `VITE_ADMIN_PASSWORD` в `.env`.
* **Бессрочный VIP-доступ**: Аккаунту администратора навсегда присвоен максимальный тариф **«Агентство / Team (VIP)»**.
* **Центр поддержки**: Приём тикетов и ответы клиентам.
* **Выдача тарифов по почте**: Назначение тарифа с расчётом `expiresAt` и отображением оставшегося срока.
* **База реальных пользователей**: Реестр с отображением английского имени, email, даты регистрации, IP и количества отчётов.
* **Выгрузка логов**: Экспорт журнала активности в **CSV** и **JSON**.

---

#### 8. Безопасность и защита от абуза
* **Лимит на создание аккаунтов (Максимум 3 с одного IP)** с возможностью сброса в админке.
* **Защита от DDoS-атак и Rate Limiting**: Дросселирование запросов (код 429 при флуде).
* **Поддержка Cloudflare**: Чтение заголовков `cf-connecting-ip`, `cf-ray`, `cf-ipcountry`, `x-real-ip`.

---

### Запуск проекта

1. Распакуйте архив `Reportix.zip`.
2. Установите зависимости:
   ```sh
   npm install
   ```
3. Запустите в режиме разработки:
   ```sh
   npm run dev
   ```
4. Для сборки production-версии:
   ```sh
   npm run build
   ```
